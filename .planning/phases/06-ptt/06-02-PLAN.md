<design>
- Channel plaintext starts with a kind byte: 0x00 text, 0x01 voice frame.
- Voice frame: burst ID u32 | sequence u16 | flags u8 (start, end) | IMA ADPCM block
  (predictor, step index, 160 bytes for 320 samples). Each block carries its own decoder
  state, so a lost frame does not affect the next. 1 + 171 + 44 = 216 bytes, inside the
  220-byte payload.
- Receiver: reorder buffer of 3 frames; a missing frame is skipped once the buffer is full.
- Capture `record` (PCM16 stream), playback `flutter_soloud` (s16le buffer stream), both
  created only on Android and Windows and only used on first talk.
</design>

<limits>
- About 55 kbit/s per speaker on the wire: fine on LAN, too heavy for multi-hop BLE.
- No echo cancellation or noise suppression.
- Mouth-to-ear delay is NOT measured (no device run).
</limits>
